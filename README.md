## About ElvioNode

ElvioNode is a modern, self-hosted game server management platform designed for individuals, gaming communities, large-scale networks, and commercial hosting providers.

Built with performance, simplicity, automation, and scalability in mind, ElvioNode provides a centralized environment for managing game servers across multiple machines — without unnecessary complexity.

From a single game server to an entire hosting infrastructure, ElvioNode gives you full control over your environment.

## Key Features

- **Multi-game support** — Manage different game servers from a single platform.
- **Real-time monitoring** — Monitor resource usage, server performance, and player activity.
- **Live console** — Interact with your servers in real time.
- **File management** — Manage and edit server files directly from your browser.
- **Plugin management** — Discover, install, and update supported plugins.
- **Automation** — Schedule commands, restarts, broadcasts, and recurring tasks.
- **Backups & restoration** — Protect your server data with automated backups.
- **Multi-node architecture** — Manage multiple machines from one centralized panel.
- **Users & permissions** — Control access through granular permissions.
- **White-label branding** — Customize the platform for your own business.
- **Hosting integration** — Manage customers and integrate billing systems.
